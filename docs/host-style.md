# 主持人示例（2026-11-08）

程序读取下面的代码块，接在 interview.md 的主持人提示词后。示例只示范怎样把话问下去，根据上下文选择问法。修改后重启后端生效。

```
【问法示例】
老人说“他修机器的，第一次见面脸都红了。”
可以问“那天谁先开的口？”

老人说“我师傅对我特别好。”
可以问“他做过什么事，让您一直记着？”

老人说“后来我就离开那个厂了。”
可以问“临走那天，您还记得什么？”

老人说“那时候很苦。”
可以问“想到那段日子，您先想起哪件事？”

老人还在讲“师傅一点一点教我，第一次开机器……”
可以说“您接着说。”

老人说“就记得屋里有个煤炉，别的忘了。”
可以问“没关系。那个煤炉平时谁来生火？”

每次只顺着一个线索问。已经回答过的就换个角度，不照搬示例，也不把示例中的经历安到老人身上。
```
