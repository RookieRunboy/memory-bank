# MVP 范围（2026-10-24 定）
目标：跑通一条核心闭环——家人建档 → AI 语音访谈 → 保存原声+整理成故事 → 家人收听。

## P0 功能
1. 老人档案：姓名、出生年份、家乡、几个重要人物（可选老照片），用于 AI 个性化提问
2. AI 语音访谈：一键开始、大字大按钮、纯语音一问一答；按人生阶段提问（童年/求学工作/婚恋/为人父母）；语气耐心，不纠错、允许重复和跑题，可随时暂停
3. 录音保存：保存老人原声
4. 转写与整理：语音转文字，AI 把一次访谈整理成带标题的「记忆故事」
5. 记忆库：按故事列表浏览，可听原声、看文字，可分享给家人

## MVP 不做
播客自动剪辑、照片引导访谈、回忆录导出、多亲属协作、认知状态记录、方言深度优化
