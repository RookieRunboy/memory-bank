# 核心能力方案 v1（2026-10-24）

## 1. 引导式访谈 Agent
现状：demo 每次固定问 5 题，不会根据回答追问。
目标：一个有"访谈大纲 + 记忆"的 Agent，每轮做三件事：
- 听：拿到老人这一句的整理文本
- 想：判断情绪（开心/卡壳/难过）、提取新信息（人、地、事、时间）、看当前话题挖够没有
- 问：决定是追问细节、给台阶、安抚，还是换下一个话题；输出一句口语化提问
依据：docs/interview.md 的提示词与问题库 + 本人的「记忆档案」（见第 3 节），避免重复问已经讲过的事。

## 2. 语音识别 + 整理（类 Typeless/飞书妙记）
两层：
- ASR 层：国内流式语音识别（讯飞 / 阿里云 / 火山引擎三选一），支持方言、实时出字；原始转写全保留
- 整理层：大模型把口语转成通顺文本——去掉"嗯、那个"、重复和停顿，按意思分段，保留老人原话的味道，不编造；每段对应原声时间点，可点文字回放原声

## 3. 聊完怎么存
数据结构（一位老人一个"记忆银行账户"）：
- 老人档案：称呼、出生年份、家乡、重要人物
- 访谈记录（每次一条）：日期、阶段、完整原声、逐句[原始转写 + 整理文本 + 时间戳]
- 记忆故事：每次访谈生成 1 篇或多篇，挂上原声片段
- 记忆档案（累积知识）：人物（李建国-老伴）、地点、事件、时间线；每次访谈后自动更新，下次 Agent 先读它，接着上次聊，也能发现前后矛盾（并列保留，不纠正）
存储：后端数据库存文本和结构化信息，对象存储存音频；家人通过分享链接查看。
路演版：可先用一个轻量后端（如 Node + SQLite + 本地文件），够演示"第二次访谈 AI 记得上次聊过什么"。
