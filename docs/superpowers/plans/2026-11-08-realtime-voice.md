# 实时语音对话 Implementation Plan

**Goal:** 用户说话时右侧气泡接收真实在线转写，小忆生成文字时逐句启动播报，插话立即停止旧回复，声音指示随真实输入起伏。

**Architecture:** 沿用现有模型和声音配置，通过服务端 WebSocket 将共享麦克风 PCM 送入已配置的流式 ASR。前端使用相同 utteranceId 更新气泡；流最终结果由服务端短期保存并可供正式轮次复用，断连则回退原录音提交。主持人 POST 支持 SSE 真实增量内容，前端同一可取消 TTS job 按完整句子持续播放。保留原声、原始访谈稿和请求幂等。

用户本聊天已明确要求继续实现。工作基于当前未提交改动，不提交或部署。

- [x] 后端 ASR：验证现有工作区流式模型，SDK 桥、服务端凭据、有限缓冲和最终转写缓存，WebSocket代理与定向测试。
- [x] 后端主持人：SSE协议、兼容模型真实stream解析、只输出自然回复、最终结构/提示词防线不退化，缓存重试兼容。
- [x] 播放器：beginStream追加真实文本，首句先播，尾句finish，stop取消正在播和未来内容。
- [x] 前端采集：复用现有PCM与前缓冲，在线ASR生命周期、临时结果及最终原话、每轮来源与迟到结果屏蔽。
- [x] 前端交互：SSE消息与音频同步生命周期、最新问题快照、插话时冻结旧输出、真实输入波形。
- [x] 验证：单元/HTTP/浏览器合成输入回归，必要的真实服务能力探测，截图与限制记录。不能用动画伪造流，也不能把合成验收说成真人声学达标。
