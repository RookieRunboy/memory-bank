## 现在可以怎样使用

```bash
cd /Users/runbo/life/dream/memory-bank/app
npm run dev:all
```

打开 `http://localhost:5173`，使用演示档案，点首页 **开始语音访谈**。这次明确的语音操作开启小忆声音并申请麦克风；之后轮次不再点麦克风。选题可以直接说或点卡片。小忆说话、生成时都能继续讲；确认人声后本地立即停止播放。喇叭只控制输出，麦克风按钮暂停/恢复采集。手动输入、重播、结束和返回仍保留。

暂停会停止音轨，恢复重新申请同一场访谈的流。结束先提交有效尾段、等已接受的轮次与整场录音保存，再生成一次故事。故事页能回放逐轮、整场及暂停分段。网络失败的录音和问题快照先留在 IndexedDB，点击重试；刷新后从首页入口接续未结束访谈。恢复查询临时失败时保留旧访谈入口，不创建新访谈覆盖它。

百炼 SDK 已安装在本机 `app/.venv`，服务器会自动发现。其他机器按 [安装说明](../app/server/py/README.md) 安装；密钥继续使用原服务端配置。

## 改造范围

- `voice-interview.js` 持有会话和实际听到的问题快照，渲染只更新界面。初始化不把尚未播放的问题标成已听到。
- 共享麦克风供本地 VAD、逐轮 WAV、整场 WAV 分段使用。没有把 MediaRecorder 的单个 timeslice 当独立文件。默认 20ms 帧、160ms 人声确认、400ms 前缓冲、220ms 句尾、2200ms 端点等待、45s 逐轮上限、30s 整场分块，集中在 `voice-vad.js`。
- 长段分块只转写存档，最终一块才生成回复；恰好结束在分块边界时有显式终止标记，使用已保存文字接话，不转写静音、不重复原话。
- `voice-playback.js` 统一处理流式 PCM、整句 Audio、浏览器朗读、重播、缓存短回应和预取。停止会撤销请求、节点、定时器、URL，并解除等待；旧回调不能恢复播放。持续访谈不自动插播缓存短回应。
- 前端提交队列和后端按访谈串行队列保持顺序。稳定请求 ID 与结果持久化，选题/答话共用输入去重范围，重启后重试仍只保存一次；取消前端等待不撤销已接受写入。
- `transcript_turns` 原话只插入；语音选题同样保留 raw/clean 和原声。播放打断、暂停恢复单独存事件。原整场回放字段及导出保持兼容，设备切换采样率时仅重采样派生整场文件，原件保留。
- 本地离线入口保留原声和可用的浏览器转写/手动文字，不用虚构演示故事替代本次讲述。

## 延迟：模拟与真实服务分开

合成浏览器输入计时，依据同一条 trace 中的输入结束和 WebAudio 调度时间：

- 插话开始 → `AudioBufferSource.stop()`：**161.1ms，n=1**。这是 JS 停止节点时间，不是扬声器实测停声。
- VAD 人声确认：**160ms**。结束等待：**2200ms**。
- 有效新回复首样本调度：**2355.3、2371.5、2417.6、2389.9、2359.5ms，n=5，P50 2371.5ms**；包括选题答复，排除被抑制回复与恢复后的重播。
- 模拟 TTS 首音频字节 **43.7–52.4ms**，播放预排 **20.1–21.6ms**；普通后端 RTT **86.4–105.9ms**，语音选题约 **6.4ms**。人为设置约 1.7s 的迟到回复被抑制。
- 缓存短回应默认不自动播放；取消行为已测，没有用短回应冒充正式首声。

完整技术事件见 [synthetic-results.json](../app/screenshots/continuous-voice/synthetic-results.json)。浏览器 `window.__voiceMetrics` 只保留有界技术事件，不记录转写或录音。

## 尚需实际验收与建议

**尚未验证**真实麦克风、扬声器外放 AEC、真人轻声和咳嗽/敲击、不同房间背景声、iOS Safari / Android Chrome 的 HTTPS 流程与后台切换。当前请求设备 AEC，并做能量/频谱/连续人声确认，但声学启发式无法保证所有设备上分清回声、音乐和轻声人声。不能宣称真实外放零自打断或硬件停声 ≤300ms。

建议真机用合成播放或演示者连续聊五轮，记录首次权限、外放/耳机、噪声、轻声、2–4s 找词停顿、开场/回答中插话、关麦后系统指示、网络中断与恢复。两端手机必须 HTTPS，并回听首尾字及整场暂停边界。

延迟优化优先检查现有供应商的网络路径、冷/热连接和配额状态，评估复用百炼连接、主持人首句流式输出后立即启动现有 TTS。当前 2.2s 停顿窗口优先保护慢速叙述，不用大幅缩短端点掩盖后端 6–13s 等待。端到端实时供应商切换仍需单独对照决策。

部署边界仍为本仓库当前的单进程 sql.js；多进程需要数据库级并发保护。整场派生 WAV 每次上传重建，超长访谈有磁盘开销；可以后续改为结束时合并。未上传音频依赖浏览器本机存储，清除站点数据会清除它，存储不可用时应保留当前页面并重试。
