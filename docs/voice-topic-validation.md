# 2026-11-08 访谈串题修复

用户报告：第一句说“第一次参加黑客松比赛”，小忆却问婚礼；纠正后又念出无关候选。同时要求移除语音状态下的常驻安抚提示。

## 已确认原因

- 序号正则把“第一次”的“第一”截成选项一，直接命中第一张婚礼卡，未调用主持人模型。
- 自选话题只存为选择记录，后续主持人的 `turns` 不包含首次讲述。
- 原有提示要求换话题时进入候选菜单，且题库外内容必须映射到最近节点。用户纠正也可能触发这个流程。
- 问句去重的固定兜底均为家具、做饭等家庭问题，可能再次把非家庭故事带偏。

## 当前行为

仅完整、明确的选项或操作句驱动卡片。自然讲述进入同一套主持人、SSE、TTS 流程，首句、分段尾句、重试和刷新后的上下文均保留。旧会话里被误存为选择的实质讲述也会从原始记录恢复为模型上下文，原始访谈稿不改写。

题库只供参考与归档，不覆盖用户的话题。没有匹配节点可保留未分类；模型异常时保留当前内容，不推进到婚礼等预设问句，也不借旧题目把“他”认成配偶。未选择的第一张卡不再成为会话标题。

语音状态仍显示“正在听／小忆在说”等必要状态。常驻“您接着说，停一会儿也没关系”和关闭麦克风的泛提示已移除；错误与实际通知保留，空提示行隐藏。
