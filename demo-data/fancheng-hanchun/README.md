# 范成采访寒春：完整演示数据

范成是采访者，寒春是受访者。寒春（Joan Hinton，1921—2010）的公开生平提供历史骨架；全部问答、回忆措辞、具体动作与内心描写是为本项目创作的虚构演示，不是寒春真实访谈、录音或逐字引语。2026 年日期只是模拟访谈排期。

这套数据包含 6 场访谈：战后芝加哥与杨振宁做实验、较早在费米指导下参加曼哈顿计划、与阳早相识成家、陕北三边牧场养牛、北京奶牛场机械改进、工作笔记与记录习惯。

交付规模：81 轮问答，原始回答共 8,727 字符，6 篇故事共 2,249 字符，45 个人物／地点／物件条目。每场约 13—14 轮。

## 从哪里看

- `user.json`：范成的演示采访者资料和参与访谈清单。
- `profile.json`：寒春的讲述者档案，采访者单独关联。
- `sessions/`：6 个唯一内容源，包括原始对白、轻度整理、逐轮实体和故事出处。
- `raw/`：适合排练、配音、录屏准备的对话 TXT，以及带稳定句子 ID 的 JSON。
- `processed/transcripts/`：清掉口头重复后的问答稿，保持说话人的意思。
- `processed/stories/`：6 篇第一人称记忆故事及段落出处。
- `processed/interview-history.json`：范成的 6 次参与记录、故事关联和估算时长。
- `processed/archive.json`、`entities.json`、`topic-state.json`：项目记忆档案、人地物、话题状态；每条提取项都能回到原始轮次。
- `processed/app-snapshot.json`：与项目实际 SQLite 表及 JSON 字段对应的完整快照。
- `research/`：公开来源、事实边界、来源之间存在分歧的细节。
- `VIDEO-WALKTHROUGH.md`：录屏顺序和解说提纲。
- `fancheng-hanchun-demo.zip`：便携完整数据包。

加工成果是与现有系统格式一致、经过核对的 mock，不代表已调用线上模型进行真实转写和生成。原始稿和整理稿同时保留；故事的 `paras.refs`、档案与实体的 `sourceTurns` 指向 `i-fancheng-N-tM`。

## 在现有项目里演示

本次已经启动并验收的独立演示地址：<http://127.0.0.1:8788/#/account>。进入后选择「范成采访 · 寒春」。它使用独立演示库，不影响原有访谈。该地址依赖本机后端进程持续运行。

在 `memory-bank/app` 运行 `npm run dev:all`，打开前端，进入「我的资料」，选择「范成采访 · 寒春」。项目会新增 `demo-hanchun` 讲述者档案，保留范成 `demo-fancheng` 的采访者元数据。已有王女士、徐先生以及其他资料不变。

当前产品没有登录系统或采访者账号表；这里的范成是演示参与者档案，不冒充已实现账号登录、访问控制或亲友授权。现有页面按受访者聚合，访谈历史、故事、记忆档案均能查看范成这次采访项目的材料。

服务启动只在 `demo-hanchun` 不存在时插入，重复启动不覆盖用户编辑和访谈原稿。若调整脚本后想重新演示，使用新的独立 `DATA_DIR` 启动；不要删除原库。

```bash
# 在 memory-bank/app 目录：数据包重生成与引用校验
node scripts/export-fancheng-demo.mjs
node --test test/fancheng-demo.test.mjs

# 可选：独立演示库，不影响默认本地库
DATA_DIR=/tmp/memory-bank-fancheng-demo PORT=8788 node server/index.mjs
```

默认前端代理指向 8787；如用独立端口 8788，先执行 `npm run build`，再直接访问后端提供的页面 `http://localhost:8788/#/account`。

## 原声与日期

本包没有音频、视频、声纹克隆或历史照片；`audio` 和 `fullAudio` 均为 `null`。TXT 时间码是按台词长度估算的排练时间，不能当成真实录音时长。当前产品无音频时可能调用 TTS 朗读文字，录屏应称「朗读演示」，不能称「寒春原声」。真正录制后再把实际文件和实测时间码关联到对应轮次。

故事中的「原话摘录」只表示逐字摘自本包的虚构对话；不代表历史人物留下的原话。不要将这些句子作为史料引用。
