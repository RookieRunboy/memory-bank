# 寒春原型访谈：史实边界

核对日期：2026-11-08（Asia/Shanghai）。固定来源编号和事实编号见同目录 `sources.json`。

**这是虚构演示的研究底稿。所有拟写访谈对白、动作、场景、内心和生活细节均为创作，非真实采访，非寒春本人原话。范成是采访者，寒春是受访者。2026 年的录制日期仅为演示安排，不能标为寒春真实受访日期。**

## 人物关系

- **F01** 寒春 = Joan Hinton（琼·辛顿），不是 Alice Cook 或 Alice Hinton。[母校人物介绍 H01](https://www.bennington.edu/bennington-network/outsized-impact/joan-hinton)
- **F06** 阳早 = Erwin “Sid” Engst；韩丁 = William Hinton，是寒春兄长。康奈尔校友档核认阳早曾与韩丁做室友。相识可说经哥哥介绍，初见日期、房间、季节未确认。[康奈尔档案 H09](https://ecommons.cornell.edu/bitstream/1813/28048/1/091_06.pdf)、[新华每日电讯报道 H05](https://www.peopleweekly.cn/html/2021/renwu_0322/64594.html)

## 发现的冲突及采用方式

1. **与杨相识年份**：清华转载记到1946-01-02；2016年杨振宁访谈回忆为1947；2021年讲话说曾同实验室20个月。共同可确认的是战后芝加哥阶段，不采用精确相识日。[H03](https://www.tsinghua.org.cn/info/1023/35976.htm)、[H04期刊原文](https://wuli.iphy.ac.cn/cn/article/pdf/preview/10.7693/wl20210905.pdf)、[H04可读转载](https://www.aisixiang.com/data/145942.html)
2. **费米的身份**：可写工作上的指导者、老师；不要把宽泛“师从”扩写为正式博士导师。杨振宁访谈明确作了区分。
3. **学位**：核历史博物馆列1944博士；中文回顾列硕士，母校只稳妥写毕业后读研。演示采用“读物理研究生”，避免“已获博士”“博士毕业后”。[H10](https://ahf.nuclearmuseum.org/ahf/profile/joan-hinton/)
4. **到达与成婚**：赴上海、到延安月份及婚礼具体场所有不同报道。使用年份和地区，不拼接成精确行程。1949秋三边牧场与后来西安、北京明确分段。[学习时报 H06](https://www.peopleweekly.cn/html/2021/wenshi_1217/104049.html)
5. **试爆观测距离**：Carter晚年约记15英里，其他简介写25英里。使用“远处山坡”，不营造数值确定性。
6. **记录本**：成箱工作笔记有基地展陈依据，但没有取得原页。笔记外观、当天填写、某牛编号、翻页动作和读出的句子全部标为创作。[国机集团基地 H08](https://finance.people.com.cn/GB/8215/435221/437704/437840/index.html)

## 必须避免的误写

- “曼哈顿计划唯一或第一位女科学家”：资料本身存在夸张，采用“参与者之一”。
- “杨振宁与寒春在洛斯阿拉莫斯一起研制原子弹”：混淆战时与战后。
- “寒春1947年带着牛群撤离延安”：当时她尚未赴华。
- “1949三边牧场已有后来北京的整套挤奶、制冷系统”：设备年代错置。
- “寒春帮助中国制造原子弹／带来了核秘密”：无可靠支持，不能作为事实写入。[杨振宁讲话 H11](https://www.tsinghua.org.cn/__local/B/DA/B6/ACBBB9749359E0AE1E853BA3041_F27E5625_1B04EE.pdf)
- 将报告文学里的直接引语复制成“新发现的真实访谈”：本演示全部新写对白都只能标为虚构。
- 从晚年思想与感情逆推某次具体沉默、争吵、后悔：这些不是史料能自动证明的事实。

## 写作标注规则

每场保留 `fictionNotice` 和 `sourceRefs`；每轮 `fictionalDetails` 列明新写的动作、心理、器物外观、故障过程或个人评价。`story` 是对应演示对话的整理稿，不是独立传记，不能补入对话未出现的外部事实。`quotes` 仅摘演示 `raw` 的逐字子串，并随整场虚构标注呈现。政治信念可体现为人物原型的历史背景，具体表述不能伪装成原话。

机械工作的年代和地点另以[西安地方报道 H07](https://xian.qinfeng.gov.cn/info/1157/42120.htm)交叉核对；该报道发表于2025年，不能让2010年已去世的寒春在演示里“读过”它。
